# 第八屆「廣達游智盃」創意程式競賽：30 組 AI Prompt 提示詞集合

## 競賽規範自我檢查點 (Checklist)
1. **主題性**：作品必須**明確出現並點出該條真實河流/溪流/水圳的名稱**（於標題、對話或 UI 說明中）。
2. **動畫類（60~180秒）**：至少 1 位主角、至少 1 次背景過場轉換、故事結構完整。
3. **遊戲類（關卡 ≤ 2關）**：開場須有規則說明頁、具備操作介面、過關條件明確、難度適中。
4. **軟體工具**：Scratch 3.0 / Qblock，素材無侵權疑慮。
