# P5：真實模型端到端評估

前置：P2–P4。總體計畫定位：P5 §9。

**讀取入口**：`src/core/ai/`、`src/mcp/`、各工作包測試與成果。

**此卡要做**：先用 fake provider 測分頁、拒絕、取消與不自動套用；以使用者允許的本機模型，在多種可重播案例分別評估理解、回饋、提案與實際效果。

**驗證**：記錄模型、參數、環境、各項成功數／總數、失敗和修正輪次；每個效果用獨立測試斷言。

**完成與交接**：無模型或授權時真實模型標 not-run，不阻斷 fake provider 與其他可做工作。

共同規則見 [小上下文執行入口](README.md) 和 [執行狀態](../BRIDGE-EXECUTION-STATUS.md)。先檢查工作樹及權威內容；每次只讀相關程式與測試，完成後記錄命令、退出碼、限制與下一步。
