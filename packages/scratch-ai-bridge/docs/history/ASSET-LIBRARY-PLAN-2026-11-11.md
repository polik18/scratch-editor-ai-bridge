# 官方素材全面優化計畫

2026-11-11。目標是讓 Scratch 官方素材在 Bridge 的**每一條路徑**都「不用特別寫就會用上、要換也很容易」。
這份計畫不限於競賽，涵蓋 Game Spec、Story Spec、網頁學生流程、AI 產生 Canonical IR、MCP、CLI、Session API 和作品分析。

## 1. 原則

1. **官方素材優先。** 能找到合適的官方素材就用官方素材，程式畫的圖只當找不到時或離線時的備援，並在報告中標示。
2. **本地模型只挑、不畫。** 本地模型（oMLX 上的 Cyber-Tiel 等）只從工具給的候選清單挑名字。大模型和商業模型可以畫補充素材，
   但必須走明確的匯入路徑，並記錄來源（「AI 繪製：模型名稱」）。
3. **同一個核心，所有路徑共用。** 名稱比對、中文關鍵字、近似對照、大小與動作資訊只寫在一個模組裡，各路徑都呼叫它，
   不再各自比對。
4. **每次挑選都說清楚。** 報告寫出「角色 → 用了哪個官方素材（精確／關鍵字／近似）」，並列出其他可換的選項。
5. **離線可用。** 下載過的素材驗證 MD5 後快取起來；另外提供一次預先下載全部素材的指令。

## 2. 現況

| 路徑 | 官方素材的使用 | 問題 |
| --- | --- | --- |
| 素材資料 | `library-index.json`：343 角色（214 個有多個造型、全部附音效）、85 背景、354 音效；`library-zh.ts` 313 個中文關鍵字 | 沒有造型的寬高；中文缺少常用詞（白鷺、老人、小孩、農夫、火車、橋、垃圾…），也沒有所有素材都有中文名稱的保證 |
| Game Spec（`spec`、`make`、`make_game`） | **完全沒用** | 角色是 14 種程式畫的造型，背景只有天空和草地 |
| Story Spec（`story`、`make --story`） | 角色靠名稱比對；背景預設用程式畫的 9 張 | 本地模型自己猜名稱，常猜錯（渡船伯→Sailboat）；沒有用到動作造型和角色自帶的音效 |
| 網頁學生流程（`src/main.ts`） | AI 回覆後用 `resolveLibraryAssets` 補素材；「換素材」每個角色給 6 個候選 | 候選只依名稱關鍵字，不能搜尋全庫，不能換背景和音效 |
| AI 產生 Canonical IR／scratchblocks | `createStudentProjectInstruction` 附候選清單；`replaceModelSvg` 換掉模型畫的圖 | 候選清單固定，找不到時直接用預設圖 |
| MCP | 沒有素材工具 | `catalog.ts` 已有 `queryAssetLibrary`，但沒有對外提供 |
| CLI | 沒有素材指令 | 找素材只能翻 JSON |
| Session API（`scratch-session`） | `addSprite` 只建空角色 | 不能直接加官方角色 |
| 作品分析（`inspect`） | `inspectProjectAssetProvenance` 能分辨來源 | 報告沒寫出來，也不會建議可以換成哪個官方素材 |
| 備援圖 | `spec/looks.ts`、`story/backdrops.ts`、`visuals/presets.ts` 三套各自畫 | 重複，而且報告沒有標示「這是備援圖」 |

## 3. 核心：素材挑選器 `src/core/visuals/assets.ts`

把名稱比對收斂成一個函式，所有路徑都用它：

```ts
pickAsset({ kind: 'sprite' | 'backdrop' | 'sound', name, hints?, context? }): {
  asset?: LibrarySprite | LibraryBackdrop | SoundTuple
  match: 'exact' | 'keyword' | 'approximate' | 'none'
  note?: string                 // 例如「白鷺沒有對應素材，用了 Dove（近似）」
  alternatives: string[]        // 同類的其他選項，給報告和 feedback 用
}
searchAssets({ kind, query, tag?, limit }) // 全庫搜尋：英文名、中文名、標籤
```

- **比對順序**：先比對完全相同的名稱，再比對中文關鍵字（較長的詞優先），接著查近似對照表，再用標籤和類別，最後回傳 `none`。
- **近似對照表**：用在台灣常見、但官方素材沒有的東西。每一筆都標成「近似」，例如白鷺／黑面琵鷺 → Dove、苦花／香魚 → Fish、
  阿公 → 某個長者人物、渡船 → Sailboat、火車 → Train（若有）。
- **類別**：整理成人物、動物（陸地／水中／鳥類）、交通工具、植物、食物、物品、場景（水邊、城市、自然、室內、太空）、
  音效（收集、跳、受傷、過關、失敗、背景音樂）。`alternatives` 從同一類別挑。

### 素材資料補強（`scripts/build/generate-asset-library-index.mjs`）

- **造型寬高**：從 SVG 的 viewBox 或 PNG 的檔頭讀出寬高，寫進索引。之後要縮放到一格、或決定站在地面上的位置，都不必先下載。
- **造型用途**：辨識同一角色的多個造型是動作循環（例如 `-a`／`-b`、walk）還是不同狀態，給「動起來」和移動時的動畫使用。
- **音效分類**：把 354 個音效分成收集、跳、碰撞、成功、失敗、環境、音樂循環等類別，事件音效就可以自動挑選。
- **中文名稱全面覆蓋**：343 個角色、85 個背景，以及常用音效，每一個都至少有一個中文名稱。這項由大模型翻譯，人工抽查。
  新增測試，任何素材缺少中文名稱就失敗。

## 4. 各路徑的改善

### 4.1 Game Spec

- 沒寫 `外觀` 時，用角色名稱自動挑官方素材，例如苦花魚 → Fish、螃蟹 → Crab、金幣 → 官方的錢幣或寶石。
  也可以直接寫 `"外觀": "Pufferfish"`。真的找不到才用程式畫的備援圖。
- **碰撞和外觀分開。** 玩家原本的方塊造型保留下來當碰撞框，但設成完全透明；另外加一個「外觀」角色，每一格畫面都跟著玩家移動，
  顯示官方素材，移動時播放動作造型，受傷時閃爍。其他角色則把官方素材縮放到一格大小。這樣平台跳躍和碰牆的手感完全不變。
- 最外層或各關都可以寫 `背景`，用官方背景，換關時一起換。
- **自動音效**：收集、受傷、過關、失敗時，先用角色自帶的音效，沒有的話從音效分類挑。可以寫 `"音效": false` 關掉。
- `顏色` 改用顏色特效，讓兩個角色用同一個素材時（例如毒魚和電魚都是 Fish）看得出差別。
- 報告新增 `assets`，逐一列出「角色 → 素材（比對方式）」和其他可換的選項。

### 4.2 Story Spec

- **背景改成官方優先**：水底 → Underwater 1、溪流 → Water And Rocks、城市河岸 → City With Water、森林 → Forest、
  高山 → Mountain、田野 → Farm、夜晚 → Night City。只有找不到合適官方背景的（例如河口濕地），才用程式畫的。
- **人物角色**：整理官方人物素材的年齡、性別和服裝標籤，讓阿公、小孩、老師、農夫等人物都能挑到合適的人。
- `移到` 時自動播放動作造型；`說` 時如果角色有說話用的造型就切換過去。
- 新增 `背景音樂` 欄位（每一幕或整部動畫），從音樂循環類別挑。

### 4.3 本地模型與 make

- `make` 和 `make --story` 依需求用 `searchAssets` 挑出候選清單，大約 20 個角色、8 個背景、10 個音效，連同中文名稱放進提示詞，
  規定模型只能從清單裡挑。
- 模型寫了清單以外的名稱時，`feedback` 給出最接近的三個選項，讓模型在修正回合改正。

### 4.4 網頁學生流程

- 「換素材」改成可以搜尋全庫：輸入中文或英文、看縮圖、試聽音效，並支援換背景和音效。
- 每個角色顯示「目前用的素材」和「同一類的其他選項」，點一下就換。換過的內容會寫進作品，可以復原。

### 4.5 MCP 與 CLI

- MCP 新增 `search_assets`（用 `searchAssets`，回傳名稱、中文名、類別、造型數、音效）和 `asset_preview`（縮圖網址）。
  另外新增 live patch 操作「把角色或背景換成官方素材」，同樣要由使用者在網頁上確認後才套用。
- CLI 新增四個指令：
  - `assets search <關鍵字>`：搜尋全庫。
  - `assets show <名稱>`：列出造型、音效和大小。
  - `assets sheet <關鍵字>`：在 `output/tmp/` 產生縮圖總表 PNG，讓能看圖的大模型比較素材。
  - `assets prefetch [--all]`：預先下載素材，之後離線也能用。

### 4.6 Session API 與 Canonical IR

- `scratch-session` 新增 `add-library-sprite <名稱>` 和 `set-library-backdrop <名稱>`。
- `resolveLibraryAssets` 改用 `pickAsset`，並把每一次挑選寫進報告，包括比對方式和近似說明。

### 4.7 作品分析

- `inspect` 的教師報告新增「素材來源」一節：官方素材、學生自己畫的、AI 繪製的，各列出數量和名稱。
  這對檢查原創性和填寫授權都有用。
- 學生報告用溫和的語氣提示「這個角色可以換成官方素材 X」，只當建議。

### 4.8 備援圖收斂

- 把 `spec/looks.ts`、`story/backdrops.ts`、`visuals/presets.ts` 合併成一套備援圖。只有找不到素材或離線時才使用，報告會標示「備援圖」。
- 大模型可以為這套備援圖多畫幾張；本地模型不會碰到這一層。

## 5. 驗證

- **單元測試**：每個素材都有中文名稱；近似對照表裡的每一筆都指向存在的素材；各路徑都經過 `pickAsset`。
- **基準**：在 `research/game-quality-benchmark/` 加上「素材命中率」，記錄三項：
  - 有官方素材的角色比例，目標 80% 以上。
  - 人工判讀挑錯類別的次數，目標 0。
  - 提示詞多了多少 token。
- **試玩**：Game Spec 改用外觀角色後，現有 6 個範例的試玩必須全部通過，平台跳躍的手感不能改變。
- **畫面**：新增一個截圖檢查，畫面上不應該出現備援圖，除非報告已經標示。

## 6. 順序

| 階段 | 內容 | 完成後 |
| --- | --- | --- |
| A | 核心挑選器、近似表、中文全覆蓋、造型寬高與音效分類寫進索引 | 所有路徑都有一致、可靠的挑選基礎 |
| B | Game Spec 預設用官方素材（外觀角色、背景、自動音效）；Story 官方背景優先 | 遊戲和動畫一打開就是官方素材 |
| C | `make` 候選清單、MCP `search_assets`、CLI `assets` | 本地模型不再亂猜；大模型和人都能快速找素材 |
| D | 網頁全庫搜尋換素材、Session API、`inspect` 素材來源 | 學生和老師端完整 |
| E | 收斂備援圖、建立基準和截圖檢查 | 品質可以量化追蹤 |

每個階段各自是一組 commit，完成時測試、lint、build 都要通過。B 和 C 完成後，用本機模型重跑 `make` 的實測。

## 7. 風險

- **大小不一的素材**：官方素材縮到一格後可能太小。玩家外觀可以放大到大約 1.5 格（不影響碰撞），其他角色先用一格，看實測再調整。
- **近似會誤導**：近似對照一律標示，報告列出替代選項，不要讓學生以為那就是正確的物種。
- **提示詞變長**：候選清單要量 token，本地模型的上限沿用 `measure-game-prompt-budget.ts` 的檢查。
- **網路**：全部預先下載的容量要先量過，再決定 `--all` 要不要預設。
