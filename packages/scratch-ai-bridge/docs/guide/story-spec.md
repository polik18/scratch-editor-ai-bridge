# Story Spec（動畫描述）

用角色和場景描述一部 Scratch 動畫。工具會自動加上片頭標題卡、換場時的淡出淡入，以及片尾卡，
並檢查競賽規定：要有主角、至少換一次背景、全長在 60～180 秒之間。

在 repo 第一層執行：

```sh
npm run --silent bridge -- guide story                                                   # 印出寫作格式
npm run --silent bridge -- story output/games/<名稱>/<名稱>.spec.json --playtest          # 建置並試看
```

完整範例：`src/story/examples/river-story.json`（3 幕、約 70 秒）。

## 格式

```json
{
  "標題": "小魚的回家路",
  "主角": "小魚",
  "角色": { "小魚": { "外觀": "Fish", "大小": 60 }, "鴨子": { "外觀": "Duck" } },
  "場景": [
    { "名稱": "清澈的上游", "背景": "溪流", "動作": ["旁白 …", "小魚 出現 在 左邊", "小魚 游到 中間 3秒"] },
    { "名稱": "城市河段", "背景": "城市", "動作": ["鴨子 說「你迷路了嗎？」", "同時 小魚 轉身"] }
  ],
  "結尾": ["守護河川，從我做起", "劇終"],
  "資料來源": ["…"]
}
```

- **外觀**：Scratch 官方角色的英文名稱，例如 Fish、Duck、Crab、Frog、Parrot、Sailboat。沒寫就用角色名稱找最接近的角色。
  建置時會從 Scratch 官方素材庫下載，並把造型和音效一起放進作品；下載過的素材快取在 `output/cache/assets/`，
  之後離線也能建置。`--offline` 會略過下載，改用簡單圖形代替。
- **背景**：寫出這一幕的場景（例如「清代淡水港」「河濱公園」），工具會找最接近的官方背景，近似的會在報告註明；不要寫 Backdrop1 這類預設名稱。
  內建的河川主題背景，不需要網路：河流、溪流（水圳也算）、水底、河口（濕地、紅樹林）、夜晚、城市、
  高山（峽谷、源頭）、田野（稻田）、天空。也可以寫 Scratch 官方背景的英文名稱，例如 `Underwater 1`、`Forest`。
- **動作**：一行一件事，依順序播放。行首加「同時」，會和上一行一起開始。

| 寫法                                                  | 效果                                            |
| ----------------------------------------------------- | ----------------------------------------------- |
| `角色 出現 [在 位置]`／`角色 消失`                    | 出場、退場                                      |
| `角色 移到 位置 [N秒]`（也可寫走到、游到、飛到）      | 滑行過去，往左走時會自動轉向                    |
| `角色 說「…」[N秒]`／`角色 想「…」[N秒]`              | 對話框；不寫秒數就依字數自動計算                |
| `角色 變大`／`變小`／`大小 N`／`轉身`／`動起來 [N秒]` | 改大小、轉向、輪流換造型                        |
| `旁白 …`                                              | 畫面下方的字幕，每句最多 48 字                  |
| `等 N秒`                                              | 停頓                                            |
| `播放 音效名稱`                                       | Scratch 官方音效或中文，例如 Water Drop 1、水花 |

位置可以寫左邊、中間、右邊、左上、右上、左下、右下、舞台左外、舞台右外，或座標 `(100, -50)`。
一個角色在這一幕如果有寫「出現」，開場時會先藏起來，等到那一行才出現；沒有寫的話，這一幕一開始就站在預設位置。

## 片長

全長是以下各段相加，`story` 的報告會寫在 `seconds`：

- 開頭 1 秒、片頭標題卡 3 秒。
- 每一幕的長度，從第一個動作開始，算到最後一個動作結束。
- 每次換場淡出 0.5 秒，片尾前也有一次。
- 片尾卡 4 秒。

不在 60～180 秒之間時，建置會失敗，`feedback` 會說要增加或減少幾秒。

## 試看

`--playtest` 會用十倍速播放整部動畫，所以三分鐘的動畫大約 20 秒就能看完。它會檢查三件事：

- 開頭是片頭標題卡。
- 每一幕開始時都換成了自己的背景。
- 最後有播到片尾，而且實際播放時間和計算的片長一致。

## 和競賽規定的對應

| 規定                       | 怎麼確保                                             |
| -------------------------- | ---------------------------------------------------- |
| 60～180 秒                 | 編譯時算出片長，超出範圍就建置失敗；試看時再量一次   |
| 完整情節、清楚的開頭與結尾 | 自動加上片頭標題卡和片尾卡                           |
| 至少一位主角               | 一定要有 `主角`，而且主角要在某一幕出場              |
| 至少一次過場（換背景）     | 至少要有兩幕，而且背景不同                           |
| 素材授權                   | 只用內建背景、Scratch 官方素材，以及程式畫出來的圖形 |

河川的事實內容要由作者自己查證，並寫在 `資料來源`；片尾卡會顯示前三筆。
