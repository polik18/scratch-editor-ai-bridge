# T2c：本機線索匹配

## 輸入與前置條件
依賴：T2b。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
檢查 renderFirstHint 關鍵字與首筆 opcode；對多角色、多變數、歧義採可觀察提示或未知回退。

## 驗收與輸出
T0c 案例能定位或明示不足，不把關鍵字匹配稱作根因；測同 opcode 正反例。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
