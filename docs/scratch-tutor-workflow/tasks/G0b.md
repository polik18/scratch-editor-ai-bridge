# G0b：同題生成比較

## 輸入與前置條件
依賴：G0a,T0b。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
同模型、相同需求及修復預算比較 goboscript 與 Bridge：按鍵、碰撞、廣播、自製積木及大型合成案例。

## 驗收與輸出
報告各案例可編譯、VM、可觀察行為、素材、修復次數與耗時；含失敗、分母及不可比因素。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
