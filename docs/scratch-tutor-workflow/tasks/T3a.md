# T3a：中文腳本是否值得實作

## 輸入與前置條件
依賴：T1b。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
依原計畫第 7 節盤點 studentLabel、graph、原始映射與需求，決定是否實作；不得臆造學生測試。

## 驗收與輸出
輸出實作／暫緩及證據；資料不足標暫緩，寫明剩餘研究。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
