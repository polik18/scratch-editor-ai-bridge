# T0c：提示流程基線

## 輸入與前置條件
依賴：T0b。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
檢視 main.ts、student-help.ts、core/prompt；重現教師引用缺口、同 opcode 多角色、首筆不相關及裁切，記錄未重現案例。

## 驗收與輸出
保留教師證據契約失敗測試與各案例結果、命令和退出碼；不可憑靜態文本宣稱模型品質。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
