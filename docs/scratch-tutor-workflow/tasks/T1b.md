# T1b：預算與證據裁切

## 輸入與前置條件
依賴：T1a。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
測 36 facts／80 evidence／24,000 字元限制；補足已省略數、原因與空結果，確保觀察與證據關聯完整。

## 驗收與輸出
測超大、重名、未知、隱私與缺證據；報告大小、相關線索保留率，不超限。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
