# G0a：文字生成比較環境

## 輸入與前置條件
依賴：T0a。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
依原計畫第 9 節盤點本機版本／來源／授權與工具可用性；只用隔離環境及自製資料，不登入或發布。

## 驗收與輸出
保存環境、來源雜湊及未執行原因；工具不可用時記 blocked，不妨礙不依賴它的工作。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
