# T4b：模型與真人驗證

## 輸入與前置條件
依賴：T4a。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
依原計畫第 8 節用經允許的本機模型評估固定案例，記錄分母、模型和誤判；真人及其他瀏覽器獨立記錄。

## 驗收與輸出
模型不可用或真人未參與標 not-run；不把 fake provider 當真實模型、不把未驗證說成已通過。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
