# T1a：教師證據契約

## 輸入與前置條件
依賴：T0c。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
檢查 core/prompt/prompt.ts 和 evidence-packet.ts；教師引用可用 ID 並建立對應，或刪除 ID 要求改可定位描述；保持學生匿名。

## 驗收與輸出
先重現失敗；測每個教師引用可追溯、學生不暴露 raw ID、原始名稱與素材。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
