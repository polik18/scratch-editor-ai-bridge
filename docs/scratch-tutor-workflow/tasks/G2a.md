# G2a：可選生成設計

## 輸入與前置條件
依賴：G0d,G1b。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
只有 G0d 支持時，設計可選本機文字生成、依賴、授權、錯誤、原檔保留與確認流程；不承諾瀏覽器可用。

## 驗收與輸出
交付可審閱的介面、失敗及平台限制；不將外部發布或社群操作納入。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
