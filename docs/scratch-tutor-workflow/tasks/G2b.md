# G2b：可選生成實作與驗收

## 輸入與前置條件
依賴：G2a。先讀入口 SKILL.md、狀態摘要及本卡；原計畫只按需讀相應段落。確認 source HEAD、dirty 與寫入範圍；未通過依賴不得開工。

## 工作
依 G2a 設計實作最小可選路徑；現有網站及保留式 patch 仍可用。若 G2a 因 G0d 決策而跳過，本項也用 skip 並引用同一決策證據。

## 驗收與輸出
重跑 G0 案例及缺依賴、取消、過期 revision、保留原檔／素材、使用者確認測試，分別報告未測。
記錄具體命令、退出碼、檔案與客觀證據；尚未執行項標 not-run。先寫交接證據，再將狀態設為 done。

## 失敗與恢復
保留其他人的修改；中斷或結果不明先查證再繼續。禁止覆寫原始作品、部署、對外發布或操作帳號。完整限制見入口與原計畫。
