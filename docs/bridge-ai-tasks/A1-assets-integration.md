# A1：選擇、識別與封裝素材

前置：A0；協調 U1、P2、P4。總體計畫定位：A1 §9D。

**讀取入口**：依 A0 決定 catalog adapter，並核對 compiler、AI 工具、網頁與 raw patch 呼叫端。

**此卡要做**：先用自製 fixture 完成選擇、明示來源、驗證 bytes／MD5、保留中心／音訊 metadata、封裝和離線重載；缺失時明示，不靜默冒充官方素材。

**驗證**：測多造型、重名、損毀、重試、離線、無授權、舊 revision 與 UI／AI fake provider；可用時重現 Abby-a、Arctic。

**完成與交接**：真實官方素材／網路未驗證時標 not-run；不以素材名稱猜視覺語意。
